### 🗂️ projects

**[CS:GO Round Winner Predictor](https://github.com/vanshgurawalia/csgo-round-predictor)** · [live demo](https://csgo-round-predictor-10.streamlit.app/)  
Random Forest classifier trained on 122K+ rows predicting CT vs Terrorist round outcomes from mid-round game state. CS2-themed Streamlit UI, currently being wrapped in a FastAPI service layer.  
`python` `scikit-learn` `pandas` `streamlit` `fastapi` `random-forest`

**[FakeShield — Fake News Detector](https://github.com/vanshgurawalia/fake-news-detector)**  
NLP classifier (TF-IDF + Passive Aggressive Classifier) hitting 90%+ accuracy, with a Streamlit UI featuring confidence gauges and probability charts.  
`python` `nlp` `streamlit` `scikit-learn`

**[AI Resume Screener](https://github.com/vanshgurawalia/resume-screener)**  
Parses and ranks resumes against job descriptions using the Gemini API + PDF.js. Currently being refactored with LangChain's LCEL pattern for cleaner orchestration.  
`javascript` `gemini-api` `langchain` `pdf.js`

**[Habit Tracker](https://github.com/vanshgurawalia/Habit-Tracker)**  
CLI app in C++ for building and tracking daily habits — streaks, notes, reflection prompts.  
`c++` `cli`

**[File Analyzer](https://github.com/vanshgurawalia/File-Analyzer)**  
C++ utility that parses files, extracts metadata, and surfaces structure and stats.  
`c++` `systems-programming`
